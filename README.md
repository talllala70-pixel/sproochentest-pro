# sproochentest-pro

Luxembourgish Sproochentest prep — flashcards (lb ↔ fr) with local Piper TTS.

## Rebuilding the voice engine

`piper-engine.js` is a bundle of `src/engine.js`. To rebuild after editing the source:

```
npm install
npm run build
```

Binary assets are not generated by the build: `wasm/` (from `@diffusionstudio/piper-wasm@1.0.0`) and `ort/` (from `onnxruntime-web@1.18.0`).
